PROTOTYPE · Project and Report model throwaway

Question: What does a Project hold, and what does a Report capture, so Reports never change after they're written, even as the Project keeps building up?

Click buttons to build up a Project the way a student would: open Systems, compare, search, cite Web sources, write Reports. The key choice is switchable: new Reports either copy their data when written (a frozen snapshot) or reference Project items by ID. Each Report shows "as written" next to "as it renders now", so you can see when a later change leaks into it. TRAPPIST-1 and TOI-700 values come from the 2026-10-25 Snapshots. Search counts are illustrative, except 1,228 matched / 37 excluded, which were measured live. Byte sizes are estimates: a System is about 19 KB, measured from the agent context.
